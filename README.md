## Projetos

### [Resenhário](https://github.com/V1701ni/Resenh-rio) · [ver no ar](https://resenh-rio.onrender.com)
Plataforma web de estante virtual e resenhas de livros, desenvolvida em equipe na faculdade. Os usuários se cadastram, entram na conta (senhas protegidas com hash BCrypt), organizam os livros por status de leitura (Quero Ler, Lendo, Lido, Abandonado) e publicam resenhas com notas de 1 a 5.

`C#` `ASP.NET Core` `Entity Framework` `MySQL` `React`

### Sistema de Gestão Comercial
Sistema em console, feito em Java com orientação a objetos, que cobre o ciclo de uma operação comercial: do cadastro de clientes e fornecedores até a emissão de pedidos de venda.

`Java` `POO`

### Friends of Figma PUC (projeto vencedor)
Design colaborativo, no Figma, de uma página de prompts com IA, com contribuição na estrutura, na usabilidade e na prototipação.

`Figma` `UI/UX`

### Banco de dados SQL
Modelagem e criação de um banco MySQL com chaves primárias e estrangeiras, inserção de dados, consultas com JOIN e agregações, além de function e procedures para operações bancárias.

`MySQL` `SQL`
