## 🚀 Projetos

### 📚 Resenhário

[![Código](https://img.shields.io/badge/C%C3%B3digo-GitHub-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/V1701ni/Resenh-rio)
[![Site no ar](https://img.shields.io/badge/Site-no%20ar-4A5C58?style=flat-square)](https://resenh-rio.onrender.com)

Plataforma web de estante virtual e resenhas de livros, desenvolvida em equipe na faculdade (6 pessoas, onde atuo no back-end e no front-end).

- Cadastro e login de usuários, com senhas protegidas por hash BCrypt
- Estante organizada por status de leitura: Quero Ler, Lendo, Lido e Abandonado
- Resenhas com notas de 1 a 5

`C#` `ASP.NET Core` `Entity Framework` `MySQL` `React`

### 🏢 Sistema de Gestão Comercial

Sistema em console, feito em Java com orientação a objetos, que cobre o ciclo de uma operação comercial.

- Cadastro de clientes, fornecedores e produtos
- Emissão de pedidos de venda
- Aplica herança, interfaces, classe abstrata, padrão Singleton e organização em camadas (MVC)

`Java` `POO`

### 🏆 Friends of Figma PUC (projeto vencedor)

Design colaborativo, no Figma, de uma página de prompts com IA. Contribuí na estrutura, na usabilidade e na prototipação.

`Figma` `UI/UX`

### 🗄️ Banco de dados SQL
